How to label
Supported
Every claim the answer makes about a package is stated in that package's line of information, or is a plain rewording of it. Repeating the question's own words as the purpose is fine.
Goes beyond the information
The answer says something about a package that its line does not state: a comparison, an opinion, a fact, or something it can do. True or not does not matter. Only the information counts.
Not sure
You can defend both answers. Use it, and add a note if you can.
